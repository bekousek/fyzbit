Ochrana soukromí

Krátce a bez právničiny: naměřená data ani jména žáků nikam neodcházejí. Zůstávají v prohlížeči na tom počítači nebo tabletu, na kterém měříte. FyzBit nemá server, na který by je posílal — žádný neexistuje.

To nejdůležitější ve třech větách:

  • Aplikace nepoužívá žádné cookies — ani vlastní, ani cizí.
  • Neběží tu žádná analytika, žádný Google Analytics, žádné sledovací skripty, žádné reklamní sítě.
  • Data z měření se ukládají jen do úložiště vašeho prohlížeče, aby vám je nesmazal spadlý panel. Kdykoli je smažete jedním tlačítkem.

Co se ukládá do prohlížeče a proč

FyzBit používá dvě běžná úložiště prohlížeče — localStorage na drobná nastavení a IndexedDB na rozpracované měření. Tohle je úplný seznam; nic dalšího tam aplikace nezapisuje.

Položky v localStorage
Klíč Co obsahuje Proč
fyzbit.language cs nebo en Aby se aplikace příště otevřela ve vámi zvoleném jazyce.
fyzbit.theme light, dark nebo auto Zvolený světlý / tmavý motiv.
fyzbit.samplingHz Číslo (1–50) nebo auto Vzorkovací frekvence nastavená v Nastavení.
fyzbit.units Dvojice veličina → jednotka, například {"cm":"m"} Aby si graf pamatoval, že chcete metry místo centimetrů.
fyzbit.studentInfo Třída, jména žáků, název experimentu a poznámky — přesně to, co jste naposledy vyplnili v okně pro export PDF. Aby se při dalším exportu protokolu nemusela stejná jména psát znovu.
Položky v IndexedDB (databáze keyval-store)
Klíč Co obsahuje Proč
fyzbit.session Rozpracované měření: názvy měření, časy a naměřené hodnoty všech vzorků, anotace a název senzoru. Aby se po zavření panelu, pádu prohlížeče nebo výpadku proudu dalo měření obnovit. Při dalším spuštění se aplikace zeptá, jestli pokračovat, nebo data zahodit.

Prohlížeč si navíc ukládá samotné soubory aplikace do Cache Storage (klíč začíná na fyzbit-), aby FyzBit fungoval i bez internetu — ve třídě, kde vypadne wifi. Jsou to jen soubory webu, žádná vaše data.

Na jméno žáka pozor na sdíleném počítači. Klíč fyzbit.studentInfo obsahuje jména, která jste zadali do protokolu, a zůstane v tom prohlížeči, dokud ho někdo nesmaže. Na počítači v učebně, na který sedá další třída, je proto rozumné po hodině zmáčknout Nastavení → Smazat všechna data. FyzBit se k těm jménům nikdy nedostane — ale ten, kdo si k počítači sedne po vás, ano.

Jak data smazat

  • V aplikaci: ozubené kolo vpravo nahoře → Smazat všechna data. Smaže uložená měření, jména žáků, motiv i jazyk — všechno výše uvedené.
  • V prohlížeči: mazání dat webových stránek pro fyzbit.cz udělá totéž.
  • Anonymní okno: nic nepřežije jeho zavření. Hodí se pro jednorázové měření na cizím počítači.

Hosting a serverové logy

Web běží na GitHub Pages (GitHub, Inc., společnost skupiny Microsoft) na vlastní doméně fyzbit.cz. Je to statický hosting: server jen posílá soubory a nemá kam přijímat data.

Jako každý webový server ale GitHub vidí IP adresu, ze které stránku otevřete, a technické údaje požadavku — čas, adresu stránky, typ prohlížeče. Tyto záznamy si drží GitHub pro provoz a bezpečnost podle svého prohlášení o ochraně soukromí. Autor FyzBitu k nim nemá přístup — GitHub Pages provozovateli webu žádné logy návštěvnosti nezpřístupňuje, takže autor neví ani kolik lidí web navštívilo, natož odkud.

Připojení k micro:bitu

Připojení běží přes rozhraní prohlížeče Web Serial (USB kabel) nebo Web Bluetooth. Prohlížeč se vždy zeptá, které zařízení mu smíte vybrat, a FyzBit vidí jen to jedno, které mu ukážete. Naměřená čísla putují z desky rovnou do stránky a dál nikam.

Když v aplikaci zmáčknete Připravit micro:bit, stáhne se ze stejné adresy soubor firmwaru a přes WebUSB se nahraje do desky. I to je jednosměrná cesta — z desky se neodesílá nic.

Privacy (English summary)

Measurements and pupils' names never leave the browser — FyzBit has no server to send them to. No cookies, no analytics, no trackers.

Stored locally: five localStorage keys (language, theme, sampling rate, unit choices and the last PDF report metadata, which includes pupil names), one IndexedDB entry holding the run in progress so a crashed tab does not lose it, and a Cache Storage entry holding the app's own files for offline use. All of it is cleared by Settings → Delete all data.

Hosted on GitHub Pages. GitHub, as the server operator, sees visitor IP addresses and request metadata under its own privacy statement; the author of FyzBit has no access to those logs.
